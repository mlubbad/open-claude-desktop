# Contributor Covenant Code of Conduct

## Our Pledge

We as members, contributors, and maintainers pledge to make participation in our community a harassment-free, constructive, and welcoming experience for everyone, regardless of background, experience level, nationality, or language.

## Standards

- Focus on technical merit, reproducible evidence, and respectful feedback.
- Welcome newcomers testing local and cloud LLM setups across macOS, Linux, and Windows.
- Respect security boundaries: report vulnerabilities privately via GitHub Security Advisories (`SECURITY.md`) rather than public exploit posts.

## Enforcement

Unacceptable behavior (harassment, personal attacks, doxxing, or spam) may result in comment removal or repository ban at the maintainers' discretion. Contact the maintainer via GitHub profile (`@mlubbad`) for conduct concerns.
