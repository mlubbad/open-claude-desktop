# Bundled Fonts (100% SIL Open Font License 1.1)

All bundled typefaces are open-source and redistributed under the **SIL Open Font License 1.1** (see `OFL.txt`):

- `newsreader-latin-variable.woff2` and `newsreader-latin-italic-variable.woff2` - **Newsreader** (variable optical size 6..72, weights 300..700), designed by Production Type. Used as the primary warm editorial serif (`--font-serif` and `--font-display`).
- `noto-naskh-arabic-variable.woff2` - **Noto Naskh Arabic** (weights 400..700), by The Noto Project Authors. Provides first-class Arabic typography paired seamlessly with Newsreader.
- `noto-serif-latin-400.woff2`, `noto-serif-latin-600.woff2` - **Noto Serif** (Latin subset), concrete fallback tail of `--font-serif`.
